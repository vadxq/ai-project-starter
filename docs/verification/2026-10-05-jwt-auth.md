# JWT 登录改造验收

日期：2026-10-05。状态：代码改造和可执行的本地检查完成；Android 真实设备验收受环境阻碍，完整跨端发布门禁尚未通过。历史 OIDC 验收不代表本次结果。

## 实际改动

- Rust 管理本地账号，Argon2id 校验密码，签发 15 分钟 HS256 access JWT。
- 新增 login / refresh / logout；30 天 refresh 会话只存 token 散列，原子轮换；退出后 access 与 refresh 均失效。
- 追加 accounts / auth_sessions 迁移，保留已有 identities / items；create-user 显式创建账号，不提供注册和找回密码。
- SPA / Next / Android / iOS 使用应用内双语登录表单。移除外部认证服务、浏览器回调和 AppAuth；Web access 在内存、refresh 在 sessionStorage，移动端 refresh 在 Tink / Keychain。
- Rust OpenAPI 导出、五端快照与生成链路同步，英文 README / AGENTS 和中文 README 同步。

## 资源与未完成项

首轮 Rust Release 构建因磁盘不足失败，日志包含 No space left on device。只回收本任务生成的失败 Release 缓存、已完成 Rust 验证的依赖缓存和通过验收的 iOS DerivedData，没有清理其他工程。空间恢复后以 2 个构建 worker 复跑，Release 构建和真实认证 Smoke 已通过。

并发构建时，Debug Argon2 登录响应超过浏览器默认 5 秒等待，首轮 SPA 有 2 项、Next 有 1 项断言超时；已将登录断言等待设为 15 秒，客户端请求仍有 10 秒超时。Next 又因报告写入 ENOSPC 失败一次；空间恢复后，两端完整测试全部通过。

iOS 27 初次真实测试已通过语言与主题、登录、新增、勾选，编辑弹窗处自动化等待应用 idle 卡住，已中止；该系统的完整 CRUD 不计为通过。最新代码在 iOS 18.6 全部通过。

Android 当前系统 AVD 冷启动后发生 AssetManager.finalize 超时，system_server 崩溃，测试 APK 安装因找不到 package 服务失败，尚未执行 UI 测试。使用项目 .codex 内临时 API34 AVD，不清理或重置用户设备；该系统强制至少 6 GiB 数据分区，要求约 7.2 GiB 可用磁盘，原生分区参数无法降低限制。当前空间仍不足，最低系统真实登录测试未完成。两项环境问题不代表认证通过，不能用编译结果代替。

旧外部身份不会自动取得本地密码，也不会自动将旧事项绑定到新用户名；本次迁移保留旧数据。移动最低 / 当前系统、Release 及完整原生登录流程全部通过之前，不标记全端发布验收完成。
