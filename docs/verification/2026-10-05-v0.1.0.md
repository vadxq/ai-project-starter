## 实测发现与修复

- Xcode27 与 Rust1.96 的 Release proc-macro 链接组合失败；升级到官方 Rust1.99 后通过，工具链与文档已对齐。
- Keycloak 自定义 realm 必须包含标准 basic / profile / email scopes；已补齐标准配置，所有测试使用真实授权码流程。
- Swift OpenAPI 默认日期解码不接受后端毫秒时间；配置官方 fractional-seconds transcoder 后 iOS CRUD 通过。
- iOS27 的原生 Menu 未保留测试 identifier，测试改为使用真实可访问按钮名称；应用行为与 iOS18 一致。
- 原生请求增加会话世代检查，注销或切换用户后不回填旧请求结果；iOS 编辑失败保留输入。Web 按后端 Identity 缓存并在刷新失败时清理会话。
- Android AppAuth 使用标准 setUiLocales；仅本地devDebug配置issuer HTTP例外。Compose列表在新增 / 换页后回到页首，解决新事项被旧滚动位置隐藏的问题。
